# Content Performance Memory

## Purpose

Create a feedback loop where video recommendations improve based on historical performance.

## Track

For every published clip record:

- topic
- hook
- format
- platform
- publish date
- views
- retention
- engagement
- conversion results

## Analyze Patterns

Identify:

- winning hooks
- high-performing topics
- effective formats
- audience preferences

## Learnings

Convert performance data into future recommendations.

Example:

If educational misconception hooks repeatedly outperform generic tutorials:

Recommend stronger misconception-based openings.

## Rules

Do not optimize only for views.

Consider:

- audience quality
- community growth
- conversions
- brand alignment
