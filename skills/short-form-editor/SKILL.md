# Short Form Editor

## Purpose

Turn selected video moments into a structured short-form editing plan.

## Input

- Selected clip timestamps
- Transcript
- Target platform
- Brand style

## Editing Framework

### Opening

Optimize the first 1-3 seconds:

- Start with the strongest statement
- Remove unnecessary greetings
- Create immediate curiosity

### Pacing

Use:

- clean cuts
- appropriate pauses
- emphasis moments
- visual changes when attention drops

Avoid:

- excessive effects
- distracting transitions
- unnatural speed changes

### Captions

Captions should:

- highlight key ideas
- emphasize important words
- remain readable on mobile

### Visual Direction

Recommend:

- zoom points
- screen recordings
- B-roll
- diagrams
- supporting visuals

## Output

Provide:

- timeline editing instructions
- caption emphasis
- visual suggestions
- final export checklist
