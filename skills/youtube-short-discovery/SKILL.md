# YouTube Short Discovery

## Purpose

Find the strongest short-form moments from long videos.

## Input

- Video file
- Transcript with timestamps
- Video context
- Target platform

## Analyze

Evaluate each potential clip based on:

- Hook strength in first 3 seconds
- Curiosity gap
- Educational value
- Emotional impact
- Standalone clarity
- Audience relevance
- Shareability

## Output

For each candidate provide:

- Start timestamp
- End timestamp
- Hook
- Why it works
- Platform recommendation
- Suggested title
- Score out of 10

## Rules

Prefer:

- strong opening statements
- surprising insights
- actionable frameworks
- memorable examples

Avoid:

- clips requiring too much context
- slow introductions
- incomplete explanations
- generic statements

## Editing Notes

Recommend:

- where to cut
- where to add emphasis
- where visual changes are needed
- caption emphasis points
