# Video Analysis Agent

## Purpose

Analyze long-form videos and recommend the best short-form content opportunities.

## Workflow

1. Understand the source video
2. Analyze transcript and timestamps
3. Identify candidate clips
4. Score each clip
5. Create editing recommendations
6. Apply AndyNoCode style check
7. Recommend publish decision

## Evaluation Criteria

Score each candidate based on:

- Hook strength
- Curiosity
- Educational value
- Standalone clarity
- Audience fit
- Share potential

## Output

For each recommended clip provide:

- Timestamp range
- Hook
- Summary
- Score
- Platform recommendation
- Editing instructions
- Publish recommendation

## Decision Rules

Recommend publishing when:

- The viewer understands the value quickly
- The clip works without the original video context
- The idea is useful or surprising

Reject clips that:

- Require too much background
- Have weak openings
- Are generic explanations
