# Platform Optimization

## Purpose

Adapt video recommendations for different short-form platforms.

## TikTok

Prioritize:

- immediate hooks
- curiosity gaps
- fast pacing
- strong first seconds
- comments and discussion potential

Avoid:

- slow introductions
- excessive context

## Instagram Reels

Prioritize:

- shareability
- saves
- clean visuals
- professional presentation
- emotional connection

Avoid:

- low-quality presentation
- unclear messaging

## YouTube Shorts

Prioritize:

- completion rate
- viewer retention
- clear educational value
- subscriber conversion potential

Avoid:

- clips that depend heavily on external context

## Output

For each platform provide:

- suitability score
- recommended hook
- editing emphasis
- publishing recommendation
